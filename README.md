
- 1️⃣ What is the difference between var, let, and const?

  var, let, and const in JavaScript differ mainly in scope and reassignability. var is function-scoped (or global), hoisted, and re-declarable. let and const are block-scoped (scoped to {}), with let allowing reassignment and const prohibiting it. const requires initialization, while let and var do not.
  
- 2️⃣ What is the spread operator (...)?

  The spread operator (...) is an ES6 JavaScript syntax that expands iterables (like arrays, strings, or objects) into individual elements or properties. It is primarily used to shallow copy, merge, or pass elements of data structures efficiently without mutating the original data.

- 3️⃣ What is the difference between map(), filter(), and forEach()?

  The primary difference is their return value and purpose: map() transforms elements into a new array of the same size; filter() selects a subset of elements into a new array based on a condition; and forEach() performs an operation on each element but returns nothing (undefined). None of them mutate the original array (unless the callback function explicitly does so). 

- 4️⃣ What is an arrow function?

  An arrow function is a concise ES6+ JavaScript syntax for writing function expressions, using a => ("fat arrow") to separate parameters from the body. It offers shorter code, implicit returns for single-line statements, and binds this lexically from the surrounding scope, making it ideal for callbacks. 

- 5️⃣ What are template literals?

  Template literals are a JavaScript feature (introduced in ES6) that allow for easier string creation, interpolation, and multi-line formatting using backticks (`) instead of quotes. They allow developers to embed variables or expressions directly into strings using the ${expression} syntax, improving code readability compared to traditional concatenation.
